# bom-project
A branch of the generic vector database focused on serving Book of Mormon passages and contextual understanding. Adds theming, prompting, and contextually relevant parsing directives.

# Semantic Vector DatabaseLLM
 
Generic vector database webserver that stores context in a vector database and provides context to an LLM generator model. Marqo-db is utilized for the vector index and retrieval queries, and an LM-Studio webserver is used to host Llama.
